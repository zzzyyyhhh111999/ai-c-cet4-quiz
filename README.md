# CET-4 词汇测验（AI 辅助完成的 C 语言项目）

一个用标准 C（C99）写的控制台小程序：随机抽取 CET-4 词汇做四选一小测，自动计分、回顾错题，并把成绩追加写入 `scores.txt`。单文件、零第三方依赖。

## 编译与运行

```bash
gcc -std=c99 -O2 -o quiz main.c
./quiz
```

Windows（MinGW / Dev-C++ 自带 gcc）：

```bash
gcc -std=c99 -O2 -o quiz.exe main.c
quiz.exe
```

运行后按提示输入 `A`/`B`/`C`/`D` 即可，共 5 题；结束后屏幕显示得分与错题回顾，并在当前目录生成/追加 `scores.txt`。

## 文件清单

| 文件 | 说明 |
|---|---|
| `main.c` | 全部源码：词库结构体、洗牌抽题、四选一交互、计分、错题回顾、成绩落盘 |
| `README.md` | 本文件，含编译与运行命令 |

## AI 辅助说明

- 通过提示词让 AI 生成整体设计：结构体题库、Fisher-Yates 洗牌、菜单式答题循环、文件持久化。
- 人工复核后修正了三处 AI 常见疏漏：`srand` 在循环内重复播种导致题目不变、`scanf` 缓冲区残留导致误读、 `fopen` 未判空导致文件不可写时崩溃。
- 自测用例：① 连续输入 5 个 `A` → 正常结束并输出得分；② 输入小写 `a` → 按大写处理；③ 输入非字母 → 不计分但不崩溃；④ `scores.txt` 所在目录不可写 → 只提示、程序正常退出。

## 备注

题目与释义为演示用示例词，可直接修改 `BANK` / `DIST` 两个数组扩充题库。
